# Gobo 名字快捷查询

这个页面是给 `@gobo-file:` 手动指定用的快捷查询页。

如果你不想一条一条翻完整清单，可以先在这里按效果类型找，再复制对应文件名。

完整清单见：[gobo-catalog.md](./gobo-catalog.md)

## 怎么用

把下面任意一个完整文件名复制到提示词里：

```text
@gobo-file: GSG_Gobos_Windows_Blinds_07.jpg
```

## 快速查找

推荐家族：`Windows / Blinds`

可直接复制：

```text

GSG_Gobos_Windows_Blinds_07.jpg
GSG_Gobos_Windows_Blinds_12.jpg
GSG_Gobos_Windows_Blinds_18.jpg
```

## 按关键词反查

- 百叶窗、条纹窗影、条状投影：`Windows / Blinds`
- 窗格、方窗、建筑窗影：`Windows / Window`
- 棕榈叶、热带叶影、度假感：`Plants / Palm`
- 树叶、自然斑驳、户外叶影：`Plants / Tree`
- 水波、水面反光、泳池感：`Caustics`
- 极简线光、图形投影、科技感：`Lines`
- 破碎光、烟雾感、抽象遮挡：`Abstract`
